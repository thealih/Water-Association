# دموی صفحهٔ اصلی انجمن آب و فاضلاب ایران

این پوشه یک نمونهٔ مستقل و استاتیک از **فقط صفحهٔ اصلی** است؛ برای ارائه به کارفرما و گرفتن تأیید ظاهر طراحی آماده شده است.

- HTML، CSS و JavaScript ساده؛ بدون نصب پکیج و بدون Build.
- محتوای قابل ویرایش در `data/content.json`.
- ۱۰ خبر، ۱۰ رویداد، ۱۰ عضو حقوقی و ۱۰ عضو حقیقی نمونه؛ ۶ پیشکسوت برگزیده با نام و عکس از معرفی‌نامه‌های انجمن برای سال‌های ۱۴۰۲ تا ۱۴۰۴.
- ۳ اسلاید بنر، ۱۱ دسترسی، ۱۰ شاخص آماری، شبکه‌ها و گروه‌ها، فوتر سه‌بخشی.
- نسخهٔ موبایل: عکس بالای متن بنر، دکمه‌های فهرست اعضا زیر کارت‌ها و تمام‌عرض، فلش‌های متصل به لبه‌ها و فاصلهٔ مستقل خط آبی کنار عنوان.
- عکس‌ها، آیکون‌ها و قلم فارسی محلی‌اند. در زمان نمایش به CDN احتیاجی نیست.

برای اجرای محلی، در همین پوشه بنویسید:

```powershell
node serve.cjs
```

سپس `http://127.0.0.1:4175` را باز کنید. برای توقف، `Ctrl+C` بزنید. باز کردن مستقیم `index.html` با دوبار کلیک به‌علت محدودیت خواندن JSON در مرورگر کافی نیست.

**انتشار:** [راهنمای فارسی GitHub Pages](DEPLOY.md)

**ویرایش محتوا و تصویرها:** [راهنمای JSON](CONTENT.md)

دکمه‌های اسلایدر، ورق‌زدن کارت‌ها، منوی موبایل، جست‌وجوی محلی و پنجره‌های پیش‌نمایش مطالب کار می‌کنند. فهرست «همه اخبار/رویدادها/اعضا» در پنجرهٔ همین صفحه باز می‌شود. صفحهٔ مستقل دیگری ساخته نشده است.

ورود، ثبت‌نام، ثبت اطلاعات و پرداخت واقعی در این دمو وجود ندارند. لینک‌های خالی، پیام نمونه نشان می‌دهند؛ با واردکردن `url` واقعی در JSON، لینک فعال می‌شود.

نام‌ها و پرتره‌های تصویرسازی‌شدهٔ اعضای حقیقی و حقوقی و آمار، دادهٔ نمایشی‌اند. معرفی و عکس شش پیشکسوت برگزیده از فایل‌های انجمن ارائه‌شده توسط کاربر استخراج شده‌اند. اینماد تا ورود لینک استعلام انجمن برچسب «نمونهٔ نمایشی» دارد. اطلاعات تماس رسمی باید جایگزین شوند. منابع فایل‌های تصویری و قلم در `assets/SOURCES.md` آمده‌اند.
